# Identidad visual

Recursos reutilizables de la identidad visual de IBCE.

## Categorías

- `logos/`: logotipos y variantes.
- `palettes/`: colores en formato JSON.
- `typography/`: familias tipográficas y reglas de uso.
- `icons/`: iconos SVG.
- `mockups/`: referencias de aplicación.

Consulta `../DESIGN.md` para los principios visuales completos.
